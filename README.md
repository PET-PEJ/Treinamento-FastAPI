# Treinamento-FastAPI
Treinamento realizado para o PET-MA sobre "Introdução à FastAPI: Como construir uma API do zero", utilizando, obviamente, FastAPI como framework e SQLite como o banco de dado.

## Apresentação
Nos slides (https://canva.link/s2bccctry8eqipi), foi apresentado um pouco da escolha por trás do FastAPI e não outros "frameworks", como funciona uma API com um exemplo simples, principais rotas HTTP e como validar os dados de request e response, a diferença entre Models e Schemas, CRUD (Create, Read, Update e Delete) e status HTTP.

## Exemplo prático
Na parte do exemplo, fiz uma "live code" para mostrar boas práticas nos códigos e no momento de organizar as pastas, como uma conexão com o banco de dados é feita, como criar um modelo, schema, rota e serviço de um usuário e, no final, apresentei um desafio de apagar um usuário do DB.
